MakeSense

“Some technical documentation is written as if you already understand the thing you opened the documentation to learn. Research papers have their own version of this problem. You can finish twenty pages and somehow know less than when you started.

MakeSense takes documentation, research papers, technical articles, and other dense material and explains what they are actually saying. You can paste a URL, paste text, or upload a document, then get plain-English explanations, comparisons, examples, mental models, and visual breakdowns.

The important part is the comparisons. Instead of saying “Kubernetes uses declarative state reconciliation,” MakeSense should be able to explain what that means using something familiar, then come back and explain where the comparison stops being accurate. The goal is to give you something you can actually remember.

For research papers, it also separates what the source demonstrates from what is inferred or simply being used as an analogy. Results, benchmarks, methodology, limitations, and technical claims should have context rather than being repeated as impressive-looking numbers.

The technical direction is context engineering: document parsing, semantic chunking, retrieval, structured LLM output, source grounding, and generated diagrams. Built with Next.js, TypeScript, and Tailwind CSS.

Basically, it is the friend you wish the documentation had.”
